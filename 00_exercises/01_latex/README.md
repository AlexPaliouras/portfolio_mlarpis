# Markup languages and reproducible programming in statistics

Deliverables for Markup languages and reproducible programming in statistics (202000010).

Week1_LaTeX_AlexP.rnw = Original R sweave file to produce latex output in pdf format for this weeks exercise

Week1_LaTeX2_AlexP.rnw = Duplicate file with alternative fairytale text

Produce_latexdiff_script.R = R script for command that produces pdf with tracked changes between the resulting two pdf files from the corresponding rnw files.

Week1_LaTeXdiff_AlexP.pdf = LaTeX pdf file with tracked changes

Can run each rnw file separately if desired to obtain .tex files and test the resulting pdf outputs. Latexdiff script can be executed standalone as well given that the user has both rnw files in their working directory.
